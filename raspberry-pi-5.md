# Raspberry Pi 5

## Purpose

Secondary Linux device for future networking and cybersecurity projects.

## Planned Uses

- Pi-hole
- DNS Server
- Network Monitoring
- SSH Practice
- Docker

## Status

Currently not deployed.

## Why I Chose This Hardware

I originally purchased the Raspberry Pi 5 because I thought it was a small, unique computer with a lot of potential.
At the time, I wasn't sure what I wanted to use it for and never fully explored its capabilities.
As I continue building my home lab, I plan to repurpose it as a dedicated server for networking and cybersecurity projects
such as Pi-hole, Docker, or network monitoring. It has been running slower recently, so one of my goals is to troubleshoot the cause and optimize its performance before putting it into production.
