# Raspberry Pi 5

## Purpose

Secondary Linux device intended for networking, cybersecurity, and server-related projects.

## Why I Chose This Hardware

I originally purchased the Raspberry Pi 5 after seeing how much could be accomplished with such a small computer. At the time, I wasn't sure how I wanted to use it, but I knew it had a strong community and a wide range of applications. As my home lab has grown, I now plan to repurpose it as a dedicated server for services such as Pi-hole, Docker, network monitoring, and other Linux-based projects.

## Kit Information

- CanaKit Raspberry Pi 5 Starter Kit Pro
- Raspberry Pi 5 (8 GB RAM)
- 128 GB microSD Card
- Active cooling case
- 45W USB-C Power Supply
- HDMI Cables
- USB microSD Reader

## Current Status

The Raspberry Pi has been running slower than expected recently. One of my future goals is to troubleshoot its performance and determine whether the issue is related to the operating system, storage media, or system configuration before assigning it a permanent role in the lab.

## Future Role

- Pi-hole DNS Server
- Docker Host
- SSH Practice
- Network Monitoring
- Lightweight Web Services
