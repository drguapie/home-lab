# Dell OptiPlex 3050

## Purpose

Primary Linux workstation used for networking, cybersecurity, and home lab projects.

## Specifications

- CPU: Intel Core i5-6500
- RAM: 16 GB DDR4
- Storage: 256 GB SSD
- Operating System: Ubuntu Desktop 24.04 LTS

  ## Why I Chose This Hardware

I wanted a dedicated Linux workstation that was inexpensive, power-efficient, and capable of running networking and cybersecurity labs.
The OptiPlex 3050 met those requirements while allowing me to gain hands-on experience with Ubuntu without modifying my primary computer.

## Software Installed

- Git
- Nginx
- GIMP
- Inkscape

## Current Projects

- Linux Hardening Lab
- Web Server Lab

## Future Plans

- Docker
- Wireshark
- Virtual Machines
- SSH Key Authentication
  
I was inspired to purchase the Dell OptiPlex 3050 after watching several YouTube videos
featuring people repurposing older Windows 10 computers for Linux.
I wanted an affordable system that would allow me to learn Linux, networking, and cybersecurity
without investing in expensive enterprise hardware.
